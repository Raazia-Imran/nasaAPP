# Release checklist

## Rainfall
- [ ] Source product/run/version, UTC interval, boundaries and visual relationship reviewed.
- [ ] Ten real means manually checked; no daily-value double multiplication or pixel-sum depth.
- [ ] Missing/fill/land values never treated as zero rain.
- [ ] A/B identical dates/scales; below-threshold cue explained.
- [ ] Play/pause/stop/seek/repeated clicks cancel correctly.
- [ ] Frame, value and sound refer to same record.
- [ ] Keyboard/NVDA/200% zoom complete core; table alternative to audio.
- [ ] Actual phone-browser playback tested; no assumed PWA/offline claim.

## Optional ocean
- [ ] Independent source/reference/image gate passed.
- [ ] Absolute vs anomaly units correct; observation-reference=departure.
- [ ] Ten real examples checked on shared masks; old track stops when switching.

## Study and release
- [ ] Actual participant count/tasks/outcomes recorded with consent and limitations.
- [ ] No blindfold exercise claimed as representative accessibility testing.
- [ ] No forecast, official warning, flood-depth or unsupported causal claim.
- [ ] Offline assets/update/reset tested where claimed; local fallback ready.
- [ ] Lint/build and source checks pass; tested commit identified.
- [ ] README, citations, licenses and current AI disclosure/form complete.

Schema validation checks structure, not provenance. Synthetic fixtures test code but never become scientific evidence.
